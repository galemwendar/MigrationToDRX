## 🎯 Обзор

Набор SQL-скриптов для заполнения таблиц **Document** и **Version** системы миграции документов.

**Основной скрипт:** `INSERT_Document_Version_Data.sql`
- Создает 61 документ
- Создает 74 версии документов и их подписи
- Заполняет связанные справочные данные

**Дополнительный скрипт:** `ANALYTICS_Queries.sql`
- 17 аналитических запросов
- Проверка целостности данных
- Экспорт отчетов

## 📄 Структура документов

### Таблица Document

```sql
Id                  NVARCHAR(30)      -- Уникальный ID (формат: OU001:DOC:2024-001)
Name                NVARCHAR(250)     -- Название с номером
ДругиеПоля          NVARCHAR(MAX)     -- JSON с дополнительной информацией
CountryId           NVARCHAR(30)      -- Связь со страной
AuthorId            NVARCHAR(30)      -- Связь с сотрудником
Note                NVARCHAR(500)     -- Примечание
Result              NVARCHAR(50)      -- Результат миграции (заполняется позже)
MigrateTime         DATETIME2         -- Время миграции (заполняется позже)
MigrateMessage      NVARCHAR(MAX)     -- Сообщение миграции (заполняется позже)
```

### JSON в ДругиеПоля:

```json
{
  "номер": "П-001",
  "дата": "2024-01-15",
  "тип": "Приказ",
  "статус": "Утвержден",
  "сумма": 0,
  "контрагент": "ООО Поставщик-1",
  "валюта": "RUB",
  "период": "01-31.01.2024"
}
```

### Таблица Version

```sql
Id                  NVARCHAR(30)      -- ID версии (формат: OU001:DOC:2024-001:V1)
Filepath            NVARCHAR(3000)    -- Путь к файлу на сетевом диске
RxDocId             NVARCHAR(30)      -- ID документа (внешний ключ)
RxVersionId         BIGINT            -- Номер версии в RX системе
IsMain              BIT               -- 1=основной файл, 0=вспомогательный
IsSignature         BIT               -- 1=файл подписи, 0=обычный файл
MainDocFilepath     NVARCHAR(30)      -- ID основного файла (для подписей)
Result              NVARCHAR(50)      -- Результат миграции
MigrateTime         DATETIME2         -- Время миграции
MigrateMessage      NVARCHAR(MAX)     -- Сообщение миграции
```

## 💡 Примеры использования

### Пример 1: Получить все документы контрагента

```sql
SELECT 
    d.Id, d.Name,
    JSON_VALUE(d.ДругиеПоля, '$.контрагент') AS Контрагент,
    COUNT(v.Id) AS Файлы
FROM dbo.Document d
LEFT JOIN dbo.Version v ON d.Id = v.RxDocId
WHERE JSON_VALUE(d.ДругиеПоля, '$.контрагент') LIKE '%Поставщик%'
GROUP BY d.Id, d.Name, JSON_VALUE(d.ДругиеПоля, '$.контрагент');
```

### Пример 2: Найти документы с подписями, требующие внимания

```sql
SELECT DISTINCT
    d.Id, d.Name,
    COUNT(CASE WHEN v.IsSignature = 1 THEN 1 END) AS Подписей,
    d.Result
FROM dbo.Document d
INNER JOIN dbo.Version v ON d.Id = v.RxDocId
WHERE v.IsSignature = 1
GROUP BY d.Id, d.Name, d.Result
HAVING d.Result IS NULL;
```

### Пример 3: Статистика по авторам

```sql
SELECT 
    JSON_VALUE(r.ПоляRecipientов, '$.ФИО') AS ФИО,
    JSON_VALUE(r.ПоляRecipientов, '$.должность') AS Должность,
    COUNT(d.Id) AS [Кол-во документов],
    SUM(CAST(JSON_VALUE(d.ДругиеПоля, '$.сумма') AS INT)) AS [Сумма]
FROM dbo.Recipient r
LEFT JOIN dbo.Document d ON r.Id = d.AuthorId
WHERE r.[Type] = 'Сотрудник'
GROUP BY 
    JSON_VALUE(r.ПоляRecipientов, '$.ФИО'),
    JSON_VALUE(r.ПоляRecipientов, '$.должность')
ORDER BY [Кол-во документов] DESC;
```

### Пример 4: Поиск документов без версий

```sql
SELECT d.Id, d.Name
FROM dbo.Document d
LEFT JOIN dbo.Version v ON d.Id = v.RxDocId
WHERE v.Id IS NULL;
```

### Пример 5: Получить все версии документа

```sql
SELECT 
    v.Id, v.Filepath,
    CASE WHEN v.IsMain = 1 THEN 'Основной' 
         WHEN v.IsSignature = 1 THEN 'Подпись'
         ELSE 'Вспомогательный' END AS Тип
FROM dbo.Version v
WHERE v.RxDocId = 'OU001:DOC:2024-002'
ORDER BY v.IsMain DESC, v.IsSignature ASC;
```

## ❓ Часто задаваемые вопросы

**Q: Можно ли добавить больше документов?**
A: Да, скопируйте блоки INSERT и измените ID, Name и другие параметры.

**Q: Как добавить новое поле в JSON?**
A: Просто добавьте ключ-значение в JSON: `{"новое_поле": "значение"}`

**Q: Как найти ошибки в данных?**
A: Используйте запросы 13 (целостность ссылок) и 9 (документы без описания)

**Q: Можно ли использовать реальные пути файлов?**
A: Да, замените значения в столбце Filepath на реальные пути к файлам
